# Airport Flight Simulator

This project was developed as part of the Object-Oriented Programming 2 course at the School of Electrical Engineering, University of Belgrade.

It is a Java desktop application for managing airports and flights, with a graphical interface and flight simulation.

The project uses Java AWT for the interface and Gson for working with JSON files.

The `src` folder contains the Java code, and the CSV and JSON files contain sample data.

**Note:** Gson 2.10 is required to compile and run the project. The library is not included in this repository.
